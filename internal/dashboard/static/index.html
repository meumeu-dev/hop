Commandes utiles

hop config — configure Cloudflare (domaine + token)

hop config --show — affiche la config

hop tunnel setup — tunnel Cloudflare permanent

hop ai <question> — assistant AI (Workers AI Cloudflare, opt-in)

hop ai --enable — active l'assistant AI

hop ai --mcp <url> — connecte un LLM externe via MCP (Claude, GPT, etc.)

hop ai --limits — affiche l'utilisation Workers AI

hop send <machine> <fichier-ou-url> — envoie fichier, dossier ou telecharge URL ; affiche taille, vitesse et checksum MD5

hop receive <machine> <chemin> — recoit un fichier depuis une machine distante

hop tunnel quick — tunnel rapide via Pinggy (zero install)

hop export / import — backup/restore chiffre

hop update — mise a jour + checksum SHA256

Pairing

Connecte deux machines en un seul geste. Cles SSH echangees, chiffrement E2E, detection reseau auto.

Initier un pairing

Scanne le QR avec l'app Hop ou entre le token sur l'autre machine

Rejoindre (coller un token)

Modes de pairing

Auto — hop pair. LAN + relay en parallele, premier qui repond gagne.

LAN — hop pair -m lan. Broadcast UDP direct, zero internet.

Relay — hop pair -m relay. Via le worker Cloudflare (chiffre E2E).

Worker custom: configurable dans hop config (question interactive).

Export / Import

hop export — sauvegarde chiffree (fichier local)

hop export --cloud — upload chiffre sur le worker (lien 2min)

hop import <fichier-ou-token> — restaure la config

Assistant IA

L'assistant IA n'est pas active.

Pour l'activer, lance dans un terminal :

hop ai --enable

Il connait tes machines, services et aliases, et peut proposer des commandes hop a executer. Utilise Cloudflare Workers AI (CF requis).
