Pairing

Connecte deux machines en un seul geste. Cles SSH echangees automatiquement, chiffrement E2E.

Attendre un pairing

Dans le terminal :

hop pair

Essaie d'abord le LAN (3s), puis bascule sur le relay.

Se connecter

Entre le token de l'autre machine :

3 modes de pairing

LAN — hop pair (defaut si meme reseau). Broadcast UDP, aucun internet requis.

Worker relay — hop pair (fallback auto). Relay chiffre E2E via Cloudflare Worker.

GitHub Gist — hop pair --gist. Utilise un Gist prive comme relay. Necessite gh CLI.

Self-hosted: hop server --port 8899 lance un relay standalone, puis hop worker url http://mon-serveur:8899

Chiffrement AES-GCM + Argon2id. Le relay ne voit jamais les donnees en clair.

Configuration Cloudflare

Trouvable sur dash.cloudflare.com/profile/api-tokens → Global API Key
